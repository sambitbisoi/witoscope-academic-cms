## 3. Importer changes

| `import:science` | **Refuses to run** unless `--from-excel` is given ("The Science master is retired; the CMS is the master for content rows since 17 Nov 2026"), and only while `content_rows_owner = cms`. | `import:updates` | A Level change recomputes the current version's tier (Q20), audited as `derived_update` |
| `held-out:add` (new) | `npm run held-out:add -- --file <chapter.json> --keys K1,K2 --batch <name> [--proposals <file>] [--reason-csv <held_out.csv>] [--dry-run]`: the D18 backfill, also usable later. | `db:verify` | New checks: tier = formula(Level basis) on every Math version · held-out records: no near-copy, citation-only originality shape, no `*.book.json` keys or book text fields, placed ⇒ question exists · content rows: retired ⇒ reason, CMS rows ⇒ originality empty and source CMS, `misconceptions` text = active items · `cms_approval_blockers` runs |
