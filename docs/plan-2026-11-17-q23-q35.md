## Q35: Science import reads the 5 drivers

| What | How |
|---|---|
| Columns (optional; a file without them imports as before) | `Reading` (1–5) · `Steps` (1–20) · `Inhibition` (0–3) · `Visual` (0–3) · `Irrelevant info (Y/N)` |
| Value rules | Same as Edit (`shared/edit-checks.ts`): whole numbers in range; Y/N (Yes/No) for Irrelevant info. The ranges live in one place, `SCIENCE_DRIVERS` in `shared/science.ts` |
| Bad value | That question is **held**: nothing is written for it (no half-tagged import), and the report lists it as `HELD <Q ID>: Reading "7" is not a whole number from 1 to 5`. The other questions still import. It is also in the import's error report. It is **not** sent to the Held-out tab, which is for placing items with a known topic **[inferred]** |
| Blank | Stays blank: attributes pending. When all 5 are given, the database clears "attributes pending" (existing trigger) |
| Replaced draft | An unedited imported draft that is replaced gets the file's values; "attributes pending" is recomputed |
| Where | `scripts/lib/science-master.ts` (parse + check), `scripts/lib/science-import.ts` (write). The generation import is the same code path (`import:science` reads the Science thread's file, decision §10.11 of the Round 2 plan) |
| Docs | `docs/science-import-format.md`: new columns + an example row |
| Migration | None |

## Q23: edit linked content rows on a Science draft

| What | How |
|---|---|
| Where | The Science review box (question detail) and the Science Edit form: a **Linked content** section. One component (`web/src/LinkedContent.tsx`) with its own explicit Save |
| Actions | **+ Link a row** (search by row ID or text; not retired rows; role primary / secondary / supporting) · change a link's role · remove a link · Save / Reset |
| Roles | primary = direct, rank primary · secondary = direct, rank secondary · supporting = supporting (rank context). Same table, `cms_question_content_rows` |
| Rules (DB) | Exactly one primary, and it is confirmed by this Save · each row exists (a newly linked row must not be retired) · the misconception targeted, a wrong option's misconception item and a concept-error target row must stay on linked rows: removing such a row, or demoting it to supporting, is refused with "clear the reference first" · open drafts only (approved: Edit → new version, links carried as today) |
| "Demote" | Means moving a referenced row from direct (primary/secondary) to supporting. Moving the primary to secondary is allowed (needed to switch the primary) **[inferred]** |
| Audit | One `cms_reviews` row, before → after (the full link list), with the reason: action `science_review` on table `cms_question_content_rows`, diff key `links`. (A new action name would need the action CHECK dropped and re-added; the existing action avoids any drop.) The draft is marked edited (so an import never replaces it) |
| Migration | **0044, adds only**: `cms_save_content_links(p jsonb)` + `cms_content_links_state(version_id)`. No table change, no drop, no rename, no data change |
| Tests | DB tests for each rule; screenshots at 1440 and 1280 px |
